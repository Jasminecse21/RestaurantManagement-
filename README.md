# 🍽️ Restaurant Management Website

A simple and responsive website that provides information about a restaurant, food menu, services, and contact details.

## ✨ Features

- 🏠 Home Page
- 🍴 Food Menu
- 👨‍🍳 About Us Page
- 📞 Contact Us Page
- 🔗 Easy Navigation Between Pages
- 🎨 Simple and Attractive User Interface
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🎯 Objective

To design and develop a simple multi-page restaurant website that allows users to explore the restaurant, view the food menu, learn about the restaurant, and find contact information easily.
